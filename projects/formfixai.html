FormFixAI

An AI workout coach I built that analyzes exercise videos with Google Gemini 2.5 on an event-driven Azure pipeline and sends back structured, timestamped biomechanics feedback.

Overview

Good exercise form is hard to check on your own: the mistakes that cause injury are often invisible from the lifter's own point of view. FormFixAI lets you upload a video of your workout (MP4, MOV, AVI, or WebM) and get back a full breakdown: a form score from 0 to 100, the exercise identified, the muscles worked, specific improvements pinned to timestamps in the video, safety alerts, an assessed skill level, and suggested next steps.

Instead of running pose-estimation models locally, the app sends the video directly to Google Gemini 2.5 with a structured biomechanics prompt. I also include the user's profile in that prompt (training goals, known injuries, and body stats) so the feedback is actually personalized instead of generic.

Architecture

I built the whole system event-driven on Azure. Users sign in via Azure AD B2C and upload video through a Flask app running on Azure App Service. The upload lands in Azure Blob Storage, which emits an Event Grid event that triggers an Azure Function. The Function downloads the video and normalizes it with FFmpeg to 1280×720 at 12 FPS. That shrinks files by 50-80% and cuts Gemini input tokens by roughly 60%, which brings each analysis in under $0.01.

The normalized video goes to Gemini 2.5 (Flash or Pro, depending on the user's subscription tier), which returns structured JSON. Results land in Azure Cosmos DB while the frontend polls for completion. A playback mode I call FormView then overlays the timestamped AI feedback directly on the video as it plays. I trace the whole pipeline with Azure Application Insights and OpenTelemetry.

Tech Stack

Python Flask Azure App Service Azure AD B2C Blob Storage Event Grid Azure Functions FFmpeg Gemini 2.5 Cosmos DB Stripe Redis Application Insights OpenTelemetry

Key Engineering Details

  • Keeping analysis cheap: FFmpeg normalization (1280×720 @ 12 FPS) shrinks uploads 50-80% and cuts Gemini input tokens ~60%, which keeps each full-video analysis under one cent.
  • Structured AI output: Gemini returns strict JSON (form score, exercise ID, muscles worked, timestamped improvements, safety alerts, skill level, and next steps), so the app can parse and render results instead of dealing with free-form text.
  • Checking billing at every layer: I enforce Stripe subscription tiers at three independent layers: Flask request validation, the Azure Function, and Cosmos DB. On top of that there's Redis rate limiting, CSRF protection, and SAS upload URLs that expire after 24 hours.
  • Picking the right model: the pipeline selects Gemini 2.5 Flash or Pro per request based on the user's subscription tier, trading cost against analysis depth.
  • No waiting around: uploads return immediately; the frontend polls analysis status while the event-driven backend works, then renders FormView overlays on playback.
