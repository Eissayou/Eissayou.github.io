PCAP Tracker

A lightweight network traffic analyzer: drag and drop a PCAP file and instantly see where your packets are going on a world map.

Overview

Wireshark is the gold standard for deep packet inspection, but firing it up just to answer "who is this machine talking to?" is overkill. I built PCAP Tracker (published on GitHub as PcapExplorer) out of exactly that frustration: sometimes I just want traffic patterns at a glance, without wading through packet-level detail.

Drop in a .pcap or .pcapng capture, specify the IP you care about, and the tool renders a traffic timeline of packets sent and received over time, a "top talkers" list of the most frequent peer IPs, and an interactive world map showing where that traffic is geographically headed. Both IPv4 and IPv6 are fully supported.

How It Works

I wrote the backend in Go, using Google's gopacket library to parse capture files. When you upload a file along with a target IP, the server categorizes every packet as sent or received relative to that host, then geolocates the top peer IPs using a local MaxMind GeoLite2 database — a free, offline lookup with no external API calls, so captures never leave the machine. I built the frontend with React, TypeScript, and Vite; it renders the timeline charts and the interactive map from the analysis results.

I kept local setup deliberately simple: clone the repo, drop the free GeoLite2-City database into the data/ directory, and go run . brings the app up at localhost:5432. I also bundled a test-PCAP generator (cmd/gen_pcap) so I could produce sample capture files for development without recording real traffic.

Tech Stack

Go gopacket React TypeScript Vite MaxMind GeoLite2

Key Engineering Details

  • Format detection via magic bytes: I detect PCAPNG files by their 0x0A0D0D0A magic-byte signature, so both classic PCAP and PCAPNG captures work transparently.
  • Offline GeoIP: geolocation runs against a local MaxMind GeoLite2-City database instead of a paid API — no per-lookup cost, no rate limits, and capture data stays private.
  • Clean Go project layout: I keep parsing logic in a dedicated pkg/analyzer package, GeoIP reading in pkg/geoip, and a cmd/gen_pcap utility for generating test capture files.
  • Graceful shutdown: the HTTP server implements Go's graceful shutdown patterns so in-flight analyses complete cleanly on exit.
  • Dual-stack support: full IPv4 and IPv6 packet analysis, with sent/received categorization relative to any host in the capture.
